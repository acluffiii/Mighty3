OvaYonder: shared-pin links, copy and paste for Xcode

This adds one feature: when someone taps a https://ovayonder.sunovabit.org/p/?lat=…&lng=…&name=… link and has OvaYonder installed, the app opens, drops an orange pin there, and shows a card with Score the drive, Save favorite and Remove pin. Live ETA links (/eta/…) keep working as before.

Easiest way: the same changes are already on the claude/shared-pin-links branch of acluffiii/ovayonder. In Xcode: Source Control → Pull…, or switch to that branch. Then skip to Step 7. Use the copy-and-paste steps below only if you'd rather add the code by hand.

This code was written to match the existing files but was not compiled here (no Xcode in this environment). Build it once and tell me any error line; I'll fix it.

Step 1: Turn on Associated Domains (Apple Developer website, one time)

2. Click org.sunovabit.ovayonder.
3. Under Capabilities, tick Associated Domains, then click Save.

1. In Xcode, click the blue OvaYonder project, then the OvaYonder target, then Signing & Capabilities.
2. You should see Associated Domains with applinks:ovayonder.sunovabit.org. It's already in OvaYonder.entitlements.
3. If it isn't there: click + Capability, add Associated Domains, click +, and type applinks:ovayonder.sunovabit.org.

import Foundation

/// A place someone shared from OvaYonder.
///
/// The link is `https://ovayonder.sunovabit.org/p/?lat=29.7604&lng=-95.3698&name=Downtown%20Houston`.
/// Without the app, it opens a web page with the spot on a map and buttons for Apple Maps and
/// Google Maps. With the app installed, the site's apple-app-site-association file sends `/p/`
/// links to OvaYonder, and `SharedPinLink.pin(from:)` reads them. The web page applies the same
/// rules: decimal degrees in range, and a plain-text name of at most 80 characters.
public struct SharedPin: Equatable, Hashable, Sendable, Identifiable {
    public let coordinate: Coordinate
    /// The cleaned display name, or nil when the link had no usable name.
    public let name: String?

    public init(coordinate: Coordinate, name: String?) {
        self.coordinate = coordinate
        self.name = SharedPinLink.cleanName(name)
    }

    public var id: String { "\(coordinate.latitude),\(coordinate.longitude)|\(name ?? "")" }

    /// The name, or "Shared location" when there isn't one.
    public var title: String { name ?? SharedPinLink.untitled }
}

public enum SharedPinLink {
    public static let untitled = "Shared location"
    public static let maxNameLength = 80

    /// Characters left as-is in a query value. Everything else, including `&`, `=`, `+` and
    /// spaces, is percent-encoded, so any name survives the trip intact.
    private static let unreserved = CharacterSet(
        charactersIn: "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-._~"
    )

    /// The link to text: `https://ovayonder.sunovabit.org/p/?lat=…&lng=…&name=…`.
    public static func webURL(for pin: SharedPin) -> URL {
        var query = "lat=\(degreesText(pin.coordinate.latitude))&lng=\(degreesText(pin.coordinate.longitude))"
        if let name = pin.name, let encoded = name.addingPercentEncoding(withAllowedCharacters: unreserved) {
            query += "&name=\(encoded)"
        }
        return URL(string: "https://\(LiveShareLink.webHost)/p/?\(query)")!
    }

    /// Reads a shared pin from a `https://ovayonder.sunovabit.org/p/?…` link (with or without the
    /// slash after `p`) or from `ovayonder://p?…`. Returns nil for any other link, or when
    /// `lat`/`lng` are missing, not plain decimal numbers, or out of range.
    public static func pin(from url: URL) -> SharedPin? {
        let scheme = url.scheme?.lowercased()
        let host = url.host?.lowercased()
        let isWebLink = (scheme == "https" || scheme == "http") && host == LiveShareLink.webHost && url.path == "/p"
        let isAppLink = scheme == "ovayonder" && host == "p"
        guard isWebLink || isAppLink else { return nil }

        let items = URLComponents(url: url, resolvingAgainstBaseURL: false)?.percentEncodedQueryItems ?? []
        func value(_ key: String) -> String? {
            // Read the way a browser does: "+" is a space, then percent-escapes are decoded.
            items.first { $0.name == key }?.value?
                .replacingOccurrences(of: "+", with: " ")
                .removingPercentEncoding
        }
        guard let latitude = degrees(value("lat"), limit: 90),
              let longitude = degrees(value("lng"), limit: 180) else { return nil }
        return SharedPin(coordinate: Coordinate(latitude: latitude, longitude: longitude), name: value("name"))
    }

    /// Plain decimal degrees only: an optional sign, digits, and at most one decimal point.
    /// Rejects exponents, hex, "Infinity", "NaN" and empty text, then checks the range.
    static func degrees(_ text: String?, limit: Double) -> Double? {
        guard let text = text?.trimmingCharacters(in: .whitespaces), !text.isEmpty else { return nil }
        var body = Substring(text)
        if body.first == "-" || body.first == "+" { body = body.dropFirst() }
        let parts = body.split(separator: ".", omittingEmptySubsequences: false)
        let isDigit: (Character) -> Bool = { ("0"..."9").contains($0) }
        guard parts.count <= 2,
              parts.allSatisfy({ $0.allSatisfy(isDigit) }),
              parts.contains(where: { !$0.isEmpty }),
              let value = Double(text),
              value.isFinite,
              abs(value) <= limit else { return nil }
        return value
    }

    /// Trims, turns control and invisible formatting characters into spaces, collapses
    /// whitespace, and caps the name at 80 characters (79 plus "…"). Empty becomes nil.
    static func cleanName(_ raw: String?) -> String? {
        guard let raw else { return nil }
        var scalars = String.UnicodeScalarView()
        for scalar in raw.unicodeScalars {
            switch scalar.properties.generalCategory {
            case .control, .format, .lineSeparator, .paragraphSeparator:
                scalars.append(" ")
            default:
                scalars.append(scalar)
            }
        }
        let collapsed = String(scalars).split(whereSeparator: \.isWhitespace).joined(separator: " ")
        guard !collapsed.isEmpty else { return nil }
        guard collapsed.count > maxNameLength else { return collapsed }
        return String(collapsed.prefix(maxNameLength - 1)).trimmingCharacters(in: .whitespaces) + "…"
    }

    /// Six decimal places (about 10 cm), without a trailing run of zeros.
    static func degreesText(_ value: Double) -> String {
        var text = String(format: "%.6f", value)
        while text.hasSuffix("0") { text.removeLast() }
        if text.hasSuffix(".") { text.removeLast() }
        return text == "-0" ? "0" : text
    }
}

import XCTest
@testable import OvaYonderCore

final class SharedPinLinkTests: XCTestCase {
    private let downtown = Coordinate(latitude: 29.7604, longitude: -95.3698)

    func testWebURLFormat() {
        let url = SharedPinLink.webURL(for: SharedPin(coordinate: downtown, name: "Downtown Houston"))
        XCTAssertEqual(url.absoluteString, "https://ovayonder.sunovabit.org/p/?lat=29.7604&lng=-95.3698&name=Downtown%20Houston")
        let noName = SharedPinLink.webURL(for: SharedPin(coordinate: downtown, name: nil))
        XCTAssertEqual(noName.absoluteString, "https://ovayonder.sunovabit.org/p/?lat=29.7604&lng=-95.3698")
    }

    func testRoundTripKeepsAwkwardNames() {
        for name in ["Downtown Houston", "A&B=C+D", "Café Ñandú 🍔", "50% off? #1", "<script>alert(1)</script>"] {
            let url = SharedPinLink.webURL(for: SharedPin(coordinate: downtown, name: name))
            let pin = SharedPinLink.pin(from: url)
            XCTAssertEqual(pin?.name, name, url.absoluteString)
            XCTAssertEqual(pin?.coordinate, downtown)
        }
    }

    func testReadsAllLinkForms() throws {
        let forms = [
            "https://ovayonder.sunovabit.org/p/?lat=29.7604&lng=-95.3698&name=Downtown%20Houston",
            "https://ovayonder.sunovabit.org/p?lat=29.7604&lng=-95.3698&name=Downtown%20Houston",
            "https://OvaYonder.Sunovabit.org/p/?lat=29.7604&lng=-95.3698&name=Downtown+Houston",
            "ovayonder://p?lat=29.7604&lng=-95.3698&name=Downtown%20Houston",
        ]
        for text in forms {
            let pin = SharedPinLink.pin(from: try XCTUnwrap(URL(string: text)))
            XCTAssertEqual(pin?.coordinate, downtown, text)
            XCTAssertEqual(pin?.name, "Downtown Houston", text)
        }
        let literalPlus = SharedPinLink.pin(from: URL(string: "https://ovayonder.sunovabit.org/p/?lat=1&lng=2&name=A%2BB")!)
        XCTAssertEqual(literalPlus?.name, "A+B")
    }

    func testRejectsBadCoordinates() {
        let bad = [
            "", "?lng=2", "?lat=1", "?lat=abc&lng=2", "?lat=999&lng=2", "?lat=1&lng=-181", "?lat=90.0001&lng=0",
            "?lat=1e1&lng=2", "?lat=0x10&lng=2", "?lat=Infinity&lng=2", "?lat=NaN&lng=2", "?lat=.&lng=2", "?lat=--1&lng=2", "?lat=1.2.3&lng=2",
        ]
        for query in bad {
            XCTAssertNil(SharedPinLink.pin(from: URL(string: "https://ovayonder.sunovabit.org/p/" + query)!), query)
        }
        XCTAssertNotNil(SharedPinLink.pin(from: URL(string: "https://ovayonder.sunovabit.org/p/?lat=-90&lng=180")!))
        XCTAssertNotNil(SharedPinLink.pin(from: URL(string: "https://ovayonder.sunovabit.org/p/?lat=+.5&lng=-0")!))
    }

    func testOtherLinksAreNotPins() {
        XCTAssertNil(SharedPinLink.pin(from: URL(string: "https://example.com/p/?lat=1&lng=2")!))
        XCTAssertNil(SharedPinLink.pin(from: URL(string: "https://ovayonder.sunovabit.org/eta/abc123def456")!))
        XCTAssertNil(SharedPinLink.pin(from: URL(string: "https://ovayonder.sunovabit.org/px/?lat=1&lng=2")!))
        XCTAssertNil(SharedPinLink.pin(from: LiveShareLink.appURL(token: "abc123")))
        // And a pin link is never mistaken for a live ETA.
        XCTAssertNil(LiveShareLink.token(from: SharedPinLink.webURL(for: SharedPin(coordinate: downtown, name: "eta"))))
    }

    func testNameCleaning() {
        XCTAssertNil(SharedPinLink.cleanName(nil))
        XCTAssertNil(SharedPinLink.cleanName("   \n\t "))
        XCTAssertEqual(SharedPinLink.cleanName("  Two\n lines\u{202E}and\u{200B}hidden  "), "Two lines and hidden")
        let long = String(repeating: "A", count: 120)
        let cleaned = SharedPinLink.cleanName(long)
        XCTAssertEqual(cleaned?.count, 80)
        XCTAssertEqual(cleaned?.hasSuffix("…"), true)
        XCTAssertEqual(SharedPin(coordinate: downtown, name: "").title, "Shared location")
    }

    func testDegreesText() {
        XCTAssertEqual(SharedPinLink.degreesText(29.7604), "29.7604")
        XCTAssertEqual(SharedPinLink.degreesText(-95.369812345), "-95.369812")
        XCTAssertEqual(SharedPinLink.degreesText(0), "0")
        XCTAssertEqual(SharedPinLink.degreesText(-0.0000001), "0")
    }
}

Step 7: Upload the website (makes the links open the app)

Upload the latest sunovabit-site.zip to public_html in Hostinger, extract with ., and overwrite. That adds:
- ovayonder.sunovabit.org/.well-known/apple-app-site-association: tells iPhones that /eta/… and /p/… links belong to OvaYonder (Team ID 4L2HGVYY25)
- ovayonder.sunovabit.org/eta/: a short page for people who don't have the app

Check it: open https://ovayonder.sunovabit.org/.well-known/apple-app-site-association in Safari. You should see text starting with {"applinks".

Step 8: Build and test on your iPhone

1. Upload the website first, then delete OvaYonder from your iPhone and run it again from Xcode. iOS checks the app-link file when the app is installed.
2. Apple caches the file, so links can take a few hours to start opening the app after the first upload. To skip the wait while testing:
   - on the iPhone, turn on Settings → Developer → Associated Domains Development
   - temporarily change the entitlement to applinks:ovayonder.sunovabit.org?mode=developer
   - put it back before you submit to the App Store
3. Paste this link into Notes or Messages (not Safari's address bar), then tap it:
   https://ovayonder.sunovabit.org/p/?lat=29.7604&lng=-95.3698&name=Downtown%20Houston
   OvaYonder should open, move to downtown Houston, and show the orange pin with its card.
4. Long-press the link: the menu should offer Open in "OvaYonder".
5. Run the tests: Product → Test, or cd OvaYonderCore && swift test in Terminal.

For your Share button

To make the link for a pin or saved place:
----- EXAMPLE -----
let url = SharedPinLink.webURL(for: SharedPin(coordinate: place.coordinate, name: place.name))
// https://ovayonder.sunovabit.org/p/?lat=29.7604&lng=-95.3698&name=Downtown%20Houston
----- END OF EXAMPLE -----
Pass url to ShareLink or the message text. Names with &, =, +, emoji, and so on are encoded safely.
